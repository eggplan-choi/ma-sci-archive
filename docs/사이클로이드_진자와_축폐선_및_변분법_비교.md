# 지식 노트: 사이클로이드 진자와 축폐선의 기하학적 구조

> **"진자의 접선 복원력이 호의 길이에 정비례할 때, 진폭에 관계없이 완전한 등시성이 실현된다."**  
> 17세기 크리스티안 호이겐스(Christiaan Huygens)는 진폭에 따라 주기가 달라지는 원형 진자의 비선형성을 극복하고자 완벽한 등시 궤도를 역추적했습니다. 그 결과 진자가 사이클로이드 곡선을 따라 움직여야 함을 밝혀내고, 진자의 줄이 감겨 자연스럽게 사이클로이드 궤적을 그리도록 하는 **사이클로이드 축폐선(Evolute) 가이드 뺨(Cheeks)** 구조를 창안했습니다.

---

## 1. 개요 및 등시성(Tautochrone) 성립 조건

진자의 접선 방향 복원력 $F_s$ 가 최하점으로부터 측정한 호의 길이 $s$ 에 정확히 비례해야 등시 조화진동($\frac{\mathrm{d}^2 s}{\mathrm{d}t^2} + \omega^2 s = 0$)을 이룹니다.

$$F_s = -mg \sin\psi = -mg as \quad \Longrightarrow \quad \sin\psi = as$$

여기서 $\psi$ 는 접선이 수평선과 이루는 각도이며, $a$ 는 양의 비례상수입니다.  
이 내재 방정식(Intrinsic Equation) $s = L \sin\psi$ ($L = 1/a = 4R$)를 직교좌표계로 환원하면 사이클로이드의 매개변수 방정식이 도출됩니다.

---

## 2. 사이클로이드의 매개변수 방정식 유도

미소 호의 길이 $\mathrm{d}s$ 에 대해 직교 좌표의 미소 변화량은 다음과 같습니다.

* $\mathrm{d}x = \mathrm{d}s \cos\psi$
* $\mathrm{d}y = \mathrm{d}s \sin\psi$

등시성 조건식 $s = L \sin\psi$ 를 미분하면 $\mathrm{d}s = L \cos\psi \, \mathrm{d}\psi$ 가 되므로, 이를 각각 대입하여 적분합니다.

### (1) 수평 변위 $x(\psi)$ 적분
$$x(\psi) = \int L \cos^2\psi \, \mathrm{d}\psi = \frac{L}{2}\psi + \frac{L}{4}\sin 2\psi$$

### (2) 연직 변위 $y(\psi)$ 적분
$$y(\psi) = \int L \sin\psi \cos\psi \, \mathrm{d}\psi = \frac{L}{4}(1 - \cos 2\psi)$$

여기서 굴림각 $\theta = 2\psi$ 및 생성원 반지름 $R = \frac{L}{4}$ 로 치환하면, 교과서 표준 **사이클로이드 매개변수 방정식** 이 완성됩니다.

$$x(\theta) = R(\theta + \sin\theta)$$
$$y(\theta) = R(1 - \cos\theta)$$

## 4. 곡률 반경($\rho$)과 축폐선(Evolute)의 정의

곡선 위의 임의의 점 $(x, y)$ 에서 안쪽 법선 방향으로 곡률 반경 $\rho$ 만큼 떨어진 곡률 중심 $(X, Y)$ 의 자취를 **축폐선(Evolute)** 이라 합니다.

$$X = x - \rho \sin\psi$$
$$Y = y + \rho \cos\psi$$

여기서 곡률 반경 $\rho$ 는 접선 각도의 변화량 $\mathrm{d}\psi$ 에 대한 호의 길이 변화율로 정의됩니다.

$$\rho = \frac{\mathrm{d}s}{\mathrm{d}\psi}$$

---

## 5. 사이클로이드 축폐선의 엄밀한 증명

### ① 미소 호의 길이 변화율 ($\frac{\mathrm{d}s}{\mathrm{d}\theta}$)
사이클로이드 매개변수식을 미분하면 $\frac{\mathrm{d}x}{\mathrm{d}\theta} = R(1 + \cos\theta)$, $\frac{\mathrm{d}y}{\mathrm{d}\theta} = R\sin\theta$ 입니다. 반각공식을 적용하여 크기를 구합니다.

$$\frac{\mathrm{d}s}{\mathrm{d}\theta} = \sqrt{\left(\frac{\mathrm{d}x}{\mathrm{d}\theta}\right)^2 + \left(\frac{\mathrm{d}y}{\mathrm{d}\theta}\right)^2} = \sqrt{2R^2(1 + \cos\theta)} = 2R \cos\left(\frac{\theta}{2}\right)$$

### ② 곡률 반경 ($\rho$) 계산 및 연쇄 법칙
접선각 $\psi = \frac{\theta}{2}$ 이므로 $\mathrm{d}\psi = \frac{1}{2}\mathrm{d}\theta$, 즉 $\frac{\mathrm{d}\theta}{\mathrm{d}\psi} = 2$ 입니다. 연쇄 법칙에 따라 곡률 반경은 다음과 같습니다.

$$\rho = \frac{\mathrm{d}s}{\mathrm{d}\psi} = \frac{\mathrm{d}s}{\mathrm{d}\theta} \cdot \frac{\mathrm{d}\theta}{\mathrm{d}\psi} = 2 \cdot 2R \cos\left(\frac{\theta}{2}\right) = 4R \cos\left(\frac{\theta}{2}\right)$$

### ③ 곡률 중심 자취 $(X, Y)$ 의 동등성 증명
$\sin\psi = \sin(\theta/2)$, $\cos\psi = \cos(\theta/2)$ 를 대입하고 삼각함수 2배각 공식을 역적용합니다.

$$X = R(\theta + \sin\theta) - 4R \cos\left(\frac{\theta}{2}\right) \sin\left(\frac{\theta}{2}\right) = R(\theta + \sin\theta) - 2R\sin\theta = R(\theta - \sin\theta)$$

$$Y = R(1 - \cos\theta) + 4R \cos^2\left(\frac{\theta}{2}\right) = R(1 - \cos\theta) + 2R(1 + \cos\theta) = R(3 + \cos\theta) \equiv Y_0 + R(1 + \cos\theta)$$

> **결론**: 곡률 중심 $(X, Y)$ 의 자취는 생성원 반지름 $R$ 이 완벽히 같고 위아래로 반전되어 평행이동한 **또 다른 사이클로이드** 입니다. 호이겐스는 이 성질을 활용해 진자 줄의 양쪽에 사이클로이드 가이드 뺨을 세움으로써 기계식 등시 진자를 구현했습니다.

## 6. 최단강하곡선과 등시성: 변분법 vs 미분방정식의 본질적 차이

| 구분 | 최단강하곡선 (Brachistochrone) | 등시성 (Tautochrone) |
| :--- | :--- | :--- |
| **문제의 본질** | **역문제 (Inverse Optimization)**<br>두 점을 잇는 무수히 많은 가능한 곡선 후보군 중에서 중력 낙하 시간 $T$를 최소화하는 '단 하나의 최적 함수' $y(x)$를 탐색. | **정문제 / 역설계 (Differential ODE)**<br>곡선 위를 진동하는 입자의 주기가 진폭과 무관하게 일정해지기 위해 접선 방향 힘이 만족해야 할 '국소적 물리 법칙'을 규명. |
| **수학적 구조** | **범함수(Functional)의 극값 탐색**<br>$\displaystyle T[y] = \int_A^B \frac{\mathrm{d}s}{v} = \int_{x_1}^{x_2} \sqrt{\frac{1 + y'^2}{2gy}} \, \mathrm{d}x$<br>함수 전체를 변분($\delta T = 0$)시키는 **오일러-라그랑주 방정식** 적용이 불가피함. | **단순 조화진동자 운동방정식**<br>$\displaystyle m \frac{\mathrm{d}^2 s}{\mathrm{d}t^2} = -mg \sin\psi = -ks$<br>호의 길이와 접선각 사이의 기하학적 미분 관계($\sin\psi = as$)를 대입해 푸는 **상미분방정식(ODE)**으로 완결. |
| **핵심 결론** | 경로(함수) 공간 전체를 후보로 놓고 시간 적분값을 최소화해야 하므로 **변분법(Calculus of Variations)**이 강제됨. | 곡선 위의 국소적인 힘-가속도 관계를 조화진동자로 묶어 궤적을 도출하는 문제이므로 일반 **미분적분학**만으로 충분함. |

## 7. 종합 요약 및 물리·수학적 통찰

1. **동일 곡선, 상이한 수학**: 사이클로이드는 '최단강하곡선'이자 '등시곡선'이라는 경이로운 이중성을 갖지만, 이를 증명하는 수학적 도구는 문제의 층위에 따라 명확히 갈립니다.
2. **변분법의 필연성**: 최단강하는 무한한 함수 공간에서 최적의 경로를 선별하는 전역적 변분 최적화 문제입니다.
3. **미분방정식의 충분성**: 등시성은 단진동의 복원력 조건($F_s \propto -s$)을 만족하는 국소 기하를 역추적하는 상미분방정식 문제이므로 변분법 없이 완결됩니다.
4. **축폐선의 자기복제성(Self-similarity)**: 호이겐스의 축폐선 발견은 진자의 기계적 가이드 설계라는 탁월한 공학적 해법이자, 사이클로이드의 축폐선이 다시 자기 자신과 합동인 사이클로이드라는 미분기하학의 아름다운 증명입니다.
